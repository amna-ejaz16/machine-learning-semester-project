💰 Gold Price Prediction System is a Machine Learning project 
that predicts the price of gold based on real financial market 
indicators including S&P 500 (SPX), Crude Oil (USO), Silver (SLV), 
and EUR/USD exchange rate. 

A Random Forest Regressor model is trained on 2,290 records of 
historical data achieving 98.8% accuracy (R² = 0.988). 
The trained model is deployed as an interactive web application 
using Streamlit where users can input current market values 
and get instant gold price predictions — no technical knowledge required.

Built with Python, Scikit-Learn, Pandas, Matplotlib, and Streamlit.
